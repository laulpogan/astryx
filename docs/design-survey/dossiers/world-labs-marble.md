## What It Is

World Labs is Fei-Fei Li's spatial-intelligence lab (co-founded with Justin Johnson, Christoph Lassner, and Ben Mildenhall), building "world models" that perceive, generate, reason about, and let users interact with 3D space. Its first commercial product, Marble, turns a text prompt, image, video, or coarse 3D layout into a persistent, editable, exportable 3D world (Gaussian splats, meshes, video). The corporate site (worldlabs.ai) is the research-lab/company shell — About, Research & Insights (blog), Marble Labs (showcase/case-studies/learn hub), and links out to the product (marble.worldlabs.ai / platform.worldlabs.ai) and an open-source renderer sub-project (Spark, at sparkjs.dev).

## Typography

- **Display serif — Gilda Display.** Declared as `--font-gilda-display`, `font-family:Gilda Display,Gilda Display Fallback`, weight 400 only, self-hosted via woff2 `@font-face` (two unicode-range split files) with a size/ascent-tuned "Gilda Display Fallback" (`local("Times New Roman")`, `size-adjust:111.02%`) to minimize layout shift before the webfont loads. Used for every large headline on the site: "World Labs / Spatial Intelligence," "About Us," "Marble Labs," "From pixels to worlds," "Unleash your creativity with Marble," and even the 404 page ("404" / "Page Not Found"). A classic transitional serif, not italic — its presence as the _only_ display face (no secondary display sans) is a deliberate, consistent choice.
- **UI/body sans — Roobert.** Declared as `--font-roobert`, self-hosted `@font-face` at weights 400/500/700 from `.otf` files (Displaay Type Foundry's Roobert grotesk), with an ascent/descent/line-gap-tuned "roobert Fallback" (`local("Arial")`). Used for nav links, body copy, buttons, eyebrow labels, footer.
- `--default-font-family: var(--font-roobert)`; a generic `--font-mono` (system stack: ui-monospace/SFMono/Menlo/Consolas) is defined in the Tailwind v4 theme layer but no custom/branded monospace face is used anywhere visible on the site — code/monospace is not a brand signal here.
- Tracked-out uppercase eyebrow labels (e.g. "SHOWCASE") sit above showcase-card titles, using the theme's `--tracking-widest: .1em`.
- Evidence source: live CSS bundle (`/_next/static/css/dc0e790d61d43dff.css`), confirmed via direct fetch and grep for `@font-face` / `font-family` declarations.

## Color

The site's CSS custom properties (from the same bundle) show a **light** brand palette, not a dark one:

- `--foreground: #2e2e38` (ink — a near-black warm plum-gray, not pure black)
- `--background: #f9f9fb` (near-white, cool ivory)
- `--black: #2e2e38`, `--white: #f9f9fb`, `--pure-white: #fff`
- `--grey-200: #5f5f75`, `--grey-150: #73738c`, `--grey-100: #9494a8` (muted violet-grays for secondary/tertiary text)

Two hard-coded accent backgrounds appear directly in the markup and are used as full-bleed "punctuation" sections rather than a global theme:

- `#111111` — near-true-black, used for the single "Marble Labs" showcase section
- `#2A679C` — a muted steel/teal blue, used for the closing "Unleash your creativity with Marble" CTA band (and echoed in the skies of several Marble-generated illustration stills)

Tailwind v4's default OKLCH gray/red/blue scale (`--color-gray-50…800`, `--color-red-600: oklch(57.7% .245 27.325)`, `--color-blue-600: oklch(54.6% .245 262.881)`, etc.) is present in the compiled CSS but is Tailwind boilerplate — none of it is visibly used on the live pages (no red, no saturated blue outside the one hard-coded `#2A679C` band). **Correction to prior scout notes:** the site is not "dark theme base, white/light-gray text" overall — it is a predominantly light, warm-neutral shell with two intentional dark/blue full-bleed sections used as rhythm breaks. The actual _product_ (marble.worldlabs.ai, platform.worldlabs.ai sign-in) is dark-mode by default — the dark-AI-aesthetic association likely comes from the product app, not the marketing site.

## Layout

- Built on Next.js (Vercel `dpl_…` deployment IDs) + Tailwind CSS v4 (confirmed via the `--color-*`/`--spacing`/`--text-*`/`--container-*` custom-property theme layer auto-generated by Tailwind v4).
- Full-width, generously whitespaced sections on a `#f9f9fb` canvas, alternating with occasional full-bleed `#111111` or `#2A679C` bands as visual "stops."
- Two-column module pattern for concept statements: image/illustration left, large serif prose right (e.g., "Spatial intelligence transforms seeing into doing…" next to a painterly landscape still).
- Three-column card grids used twice: (1) dark "Marble Labs" section — Community Showcase / Case Studies / Learn, each a full-bleed illustrated thumbnail with a white overlaid title; (2) a second showcase row — Dwarven Caves / Splat Raycasting for Locomotion / 360° Photos to Walkable Worlds — image-first cards with caption below.
- Research & Insights (blog) index: 3-column card grid, date + author eyebrow, bold sans headline, teaser copy, "Read More."
- Closing full-bleed CTA band before the footer: serif headline "Unleash your creativity with Marble" over `#2A679C`, centered dark pill CTA, footer nav links in white directly on the same band; plain light-gray footer bar below with copyright/legal/social icons.
- A fully brand-consistent 404 page (big serif "404," serif "Page Not Found," sans body copy, dark pill "Go Home" CTA) — not a generic framework default.
- Sub-brand surfaces intentionally diverge: Spark (sparkjs.dev) uses its own red/white devtool skin; the careers link routes to an unstyled Greenhouse job board; the API link routes to the product's own dark sign-in screen. The corporate identity is scoped to worldlabs.ai itself, not force-applied everywhere.

## Motion

- **GSAP is bundled and used**, confirmed by literal strings in the production JS chunks: `"Please gsap.registerPlugin(ScrollTrigger)"`, `window.gsap`, and a `this.isSplit` / `this.chars` pattern consistent with GSAP's SplitText plugin (both ScrollTrigger and SplitText are free since GSAP's 2025 license change). No `framer-motion`, `three`, `@react-three/fiber`, or `Lenis` strings were found in the sampled chunks.
- `IntersectionObserver` usage is widespread across chunks — used to trigger scroll-based reveals. Observed live: content blocks fade/slide in with a soft opacity transition as they enter the viewport (visible mid-transition as pale gray placeholder blocks in screenshots taken during scroll).
- **Notable restraint:** despite selling a 3D/spatial product, the marketing site itself runs **no live WebGL/3D** — every "world" image on worldlabs.ai is a static, painterly, pre-rendered illustration still (Marble output exported as an image), not an interactive canvas. Real-time Gaussian-splat rendering is confined to the product app and the separate Spark renderer project.
- No reduced-motion toggle or dark/light theme switcher was found on the marketing site.

## Hero Anatomy

- First viewport is pure typography on flat `#f9f9fb` — no image, no gradient, no CTA button in the fold itself (the only CTA visible is the persistent nav's dark pill "Create with Marble").
- Two-line stacked headline: line 1 "World Labs" in `#2e2e38` Gilda Display serif; line 2 "Spatial Intelligence" directly beneath, same serif, same size, but tinted to a lighter blue-gray — a two-tone headline device (dark line + lighter tint of the same face immediately below) reused as the header pattern on About ("About Us"), Marble Labs ("Marble Labs" / "Blueprints For Building"), etc.
- Sub-headline: 3-line gray sans paragraph ("World Labs is building the next frontier of generative AI — one where models can understand and interact with the world to empower use cases from storytelling to simulation."), left-aligned, well below the headline with generous negative space.
- Nav: wordmark ("World Labs" + a small origami bird/crane glyph) far left; six text links (About, Research & Insights, Marble Labs, API, Spark, Careers) center-right; dark rounded-full "Create with Marble" button far right. Sticky across all pages, unchanged in light and dark sections.
- The first supporting image only appears one scroll down (a two-column module), and it is an illustrated, painterly Marble-generated scene (blue sky, clouds, a stone arch) — not a photo, not a screenshot.

## Components of Note

- **Recurring glass-orb/"marble" motif**: a glass sphere containing a miniature painterly landscape (mountains, a hillside town, a floating island) reused as brand ornament in at least three places — the closing footer illustration, an About-page corner graphic, and a blog-post hero image. It's a literal visual pun on the product name "Marble" (a world captured inside a marble/orb) rather than an abstract logo mark.
- **Dark 3-card showcase grid** (Marble Labs: Community Showcase / Case Studies / Learn) — full-bleed illustrated thumbnails, white overlay title, "Explore →" affordance.
- **Product app (marble.worldlabs.ai)**: dark, Pinterest-style masonry gallery of community-generated world thumbnails, left icon rail (Explore / Globe / Palette), an onboarding modal with an embedded YouTube walkthrough ("Welcome to Marble! 🌎"). Visually distinct from (darker than) the marketing shell.
- **Sign-in screen (platform.worldlabs.ai)**: dark, serif headline "Build on the World Labs Platform," OAuth buttons (Google/GitHub) plus email/password fields on dark cards — standard but on-brand.
- **Brand-consistent 404 page** — a genuinely designed error state (rare).
- **Pill CTA + circumscribed-arrow icon** is the one recurring button pattern site-wide: "Create with Marble," "Learn more about us," "Join us," "Go Home" all share the same dark rounded-full shape with a circle-arrow glyph.

## Voice & Copy

Two distinct registers:

- **Marketing copy** is spare and abstract: "World Labs is building the next frontier of generative AI — one where models can understand and interact with the world to empower use cases from storytelling to simulation." No exclamation points, no hype-inflected copy, no emoji (aside from a single emoji in the product's own onboarding modal).
- **Blog/research copy** reads as long-form academic essay, not startup content marketing. Example ("3D as code," March 3, 2026) builds a sustained analogy — "3D is code," "neural graphics is the programming language," "simulation engines are the chips" — in first-person-plural authorial voice ("We believe…", "This essay argues…"), naming the actual product (Marble, Chisel, RTFM, Spark) only in the final section. It reads closer to an arXiv position paper than a company blog post.

## Distinctive Moves

1. **The glass-marble/orb-with-a-world-inside motif** as recurring brand ornament — ties illustration directly to the product name "Marble" rather than relying on an abstract mark or logo animation.
2. **Light warm-neutral shell (`#f9f9fb`/`#2e2e38`) punctuated by hard-edged full-bleed dark (`#111111`) and saturated-blue (`#2A679C`) sections** used as rhythm/emphasis devices, not a global dark theme — corrects the common assumption (including this crawl's own prior scout note) that this is a "dark AI aesthetic" site; the dark-mode association actually belongs to the separate product app.
3. **Zero live WebGL/3D on the marketing site** despite selling a spatial-AI/3D-world product — every "world" visual is a static painterly still. The company reserves interactive rendering for the actual product and its dedicated Spark renderer project, keeping the marketing shell fast and simple.

## What Astryx Should Take

1. **Two-tone stacked headline** (bold dark line immediately followed by a lighter-tint line of the _same_ typeface) is a free hierarchy device — usable in Astryx's own marketing hero or template gallery headers without adding a second display face.
2. **Reserve one saturated accent for 1–2 "punctuation" sections** (e.g., a closing CTA band or a docs-section divider) instead of theming an entire page dark — gets a dramatic beat without inheriting the generic "AI startup = dark mode + gradient" cliché that a homepage skim of this site would wrongly suggest.
3. **Self-hosted variable-weight UI sans with a metrics-tuned fallback** (Roobert 400/500/700 + a Fallback face carrying `ascent-override`/`descent-override`/`size-adjust`) is a concrete, copyable recipe for Astryx's own docs/marketing site to kill font-swap layout shift.
4. **A brand-consistent 404/error page** is a cheap, high-craft-signal checklist item for the design-system site — most component libraries skip it.
5. **GSAP ScrollTrigger + IntersectionObserver fade/reveal-on-scroll, with zero WebGL**, is a proof point that "spatial/visual" positioning doesn't require a Three.js/R3F dependency — validates keeping Astryx's own motion system CSS-first (transitions/keyframes per the project's StyleX conventions) plus a light scroll-reveal utility, rather than reaching for a 3D engine.
6. **Tracked-out uppercase eyebrow labels** ("SHOWCASE") above card titles are a lightweight editorial signal Astryx could reuse above component-doc category headers or template-gallery sections.
7. **Let a name become a visual motif**: consider whether an Astryx concept (a token, a component family) can anchor a recurring illustration/graphic the way "Marble" anchors the glass-orb motif here — more memorable than an arbitrary stock-illustration set.
